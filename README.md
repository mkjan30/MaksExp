# MaksExp

A personal expense tracker in a single HTML file. No build step, no dependencies and no account: open the file in a browser and start adding expenses.

## Features

- Add expenses with category, payment method and status
- Quick-add for common expenses
- Monthly budget with progress on the dashboard
- Analytics by category and by payment method
- Export all expenses to CSV
- Light and dark themes
- Amounts in Bangladeshi taka (৳)

## Usage

Download or clone the repository and open `index.html` in any modern browser.

```bash
git clone https://github.com/mkjan30/MaksExp.git
```

## Good to know

Data is kept in memory for the current session only. Export to CSV before closing or refreshing the page.
